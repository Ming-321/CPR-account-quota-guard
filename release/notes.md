# v0.1.1

调整账号额度保护页面，让账号、余额和阈值更容易查看。

- 有名字时显示名字和邮箱；没名字或名字就是邮箱时，邮箱只显示一次
- 额度条改为主题色圆角样式，标出当前保护阈值
- 本周期阈值只显示数值和信息图标，点击查看固定/随机模式、随机区间及下周期设置
- 额度详情改为信息弹层，重新整理设置弹窗、明暗主题和窄屏布局

本次仅调整界面，保护规则和额度读取方式不变，已有账号设置与周期状态继续沿用。

支持 CPR **>=3.21.1、<4.0.0**，提供 Linux x86_64、ARM64 安装包及 SHA-256 校验文件。

安装步骤与号池边界见 [README](https://github.com/Ming-321/CPR-account-quota-guard#readme)。生产环境需自行升级。

验证：CPR v3.21.1 / Linux ARM64 隔离运行，使用合成上游；两个架构均通过原生构建与测试。
