# v0.1.0

首个版本：为账号设置周额度保护，支持固定阈值和每周期随机阈值，额度恢复后自动放行。

- 独立管理页面，可查看周额度、当前阈值和待生效规则
- 只读取 CPR 已有额度，不主动查询上游
- 支持 CPR **>=3.21.1、<4.0.0**
- 提供 Linux x86_64、ARM64 安装包及 SHA-256 校验文件

安装后先停用默认配置，将“插件失败时”设为“交给后续处理”，再启用并添加账号。

注意：插件不负责换号。A 被保护时，即使 B 还有额度，CPR 持续选择 A 仍可能导致请求连续失败。额度更新可能滞后，不能保证精确保留余额。

安装步骤和其他限制见 [README](https://github.com/Ming-321/CPR-account-quota-guard#readme)。

验证：CPR v3.21.1 / Linux ARM64 隔离运行，使用合成上游；两个架构均通过原生构建与测试。
